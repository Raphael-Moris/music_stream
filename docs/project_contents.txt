7. ORDRE DE LANCEMENT
================================================================================

MÉTHODE 1 : AVEC DOCKER (RECOMMANDÉE)
--------------------------------------------------------------------------------

Étape 1 : Préparation
  $ cd Projet
  $ cp .env.docker .env              # Copier la configuration

Étape 2 : Démarrage
  $ docker compose up --build        # Construire et démarrer

  OU en arrière-plan :
  $ docker compose up -d --build

Étape 3 : Vérification
  $ docker compose ps                # Vérifier l'état des conteneurs

  Les deux conteneurs doivent afficher "healthy" :
  - musicstream-mongodb
  - musicstream-app

Étape 4 : Accès
  Navigateur → http://localhost:3500

Étape 5 : Arrêt
  $ docker compose stop              # Arrêt temporaire
  OU
  $ docker compose down              # Arrêt et suppression conteneurs

--------------------------------------------------------------------------------

MÉTHODE 2 : SANS DOCKER (LOCAL)
--------------------------------------------------------------------------------

Prérequis :
  - Node.js 18+ installé
  - MongoDB 7.0+ installé et démarré

Étape 1 : Installation dépendances
  $ cd Projet
  $ npm install

Étape 2 : Configuration
  $ cp .env.docker .env
  Éditer .env et changer :
    MONGODB_URI=mongodb://localhost:27017/Streaming_platform

Étape 3 : Import base de données
  $ mongorestore --db Streaming_platform Streaming_platform/

Étape 4 : Démarrage serveur
  $ npm start                        # Mode production
  OU
  $ npm run dev                      # Mode développement (auto-reload)

Étape 5 : Accès
  Navigateur → http://localhost:3500

Étape 6 : Arrêt
  Ctrl+C dans le terminal
